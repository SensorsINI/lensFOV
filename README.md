# Event-camera FOV calculator

**Use the calculator:** [https://sensorsini.github.io/lensFOV/](https://sensorsini.github.io/lensFOV/)

Estimates horizontal and vertical field of view from pixel pitch, array size, and lens focal length. Camera presets match [jAER](https://github.com/SensorsINI/jaer) chip classes (DVS128, DAVIS240/346, DVXplorer, NRV DELTA01, Prophesee EVK4, or custom). Results use jAER `EngineeringFormat` (SI prefixes).

To run offline, open [`index.html`](index.html) in a browser (no server needed).

This site is separate from a later jAER GitHub Pages site (`https://sensorsini.github.io/jaer/`).
